## Variant: One Job, Calm

### Design stance
The page reads as a single calm task: paste broken XML, get a verdict, download the file. No modes, no steps, no decisions before the user has seen a result.

### Key choices
- Layout: single centered column, one dropzone card, result unfolds below
- Typography: DM Sans headings, Inter body, JetBrains Mono for XML
- Color: site tokens — teal accent on warm off-white, verdict colors carry the meaning
- Interaction: drop/paste/upload all collapse into one zone; verdict → chips → actions → technical details accordion

### Trade-offs
- Strong at: clarity, low cognitive load, works for a first-time user
- Weak at: power users may want more control; less "tool-like" density

### Best for
- The marketing-page audience: someone whose XML was rejected and needs the fastest path to a working file
