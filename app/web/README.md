# einvoicecheck.ae - marketing site

Next.js 15 (App Router, TypeScript) marketing site for the UAE e-invoice **preflight
validation** API. Deploys to Railway (project `einvoicecheck.ae`, env `production`).

## Positioning guardrail (non-negotiable)

Preflight validation only. The copy must never claim FTA accreditation, transmission of
legal e-invoices, replacement of an accredited service provider, or statutory archival.
The guardrail sentence lives in `src/lib/site.ts` (`GUARDRAIL`) and is rendered by
`<GuardrailNotice />` on every commercial page plus the footer of every page. Keep it there.

## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build (type-checked)
npm start
```

## Billing

**Dodo Payments**, wired up in step E2. Not live. No payment SDK is embedded anywhere in
this repo and no card details are collected. `/pricing` says so explicitly.
