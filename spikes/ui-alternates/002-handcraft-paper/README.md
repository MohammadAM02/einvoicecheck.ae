# Handcraft paper validator composition

This disposable variant makes the handcraft reference visible with CSS-only paper grain, ruled input lines, handwritten-style font stacks, wobbly borders, tape strips, tack-like labels, highlighted annotations, and wavy underlines. The paper treatment is recolored with the existing EInvoiceCheck teal, navy, neutrals, and semantic colors rather than introducing a paper-brand palette.

Only the EInvoiceCheck palette and flow/semantics are inherited: ERP output → EInvoiceCheck preflight → ASP, Prepare → Validate → Understand → Fix → Revalidate, local entry, and the Validator Station handoff. The result hierarchy and exact Buyer TRN finding are unchanged. This is a static local spike, not the production validator.
