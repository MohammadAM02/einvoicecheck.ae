# Terminal outrun validator composition

This disposable variant makes the vaporwave/outrun reference visible through terminal chrome, scanline texture, a CSS perspective grid, skewed and rotated geometry, technical mono typography, and denser command-center metadata. It stays inside the EInvoiceCheck palette: teal, navy/ink, neutral surfaces, white, and the existing semantic error/warning colors—no new neon brand palette.

Only the EInvoiceCheck palette and flow/semantics are inherited: ERP output → EInvoiceCheck preflight → ASP, Prepare → Validate → Understand → Fix → Revalidate, local entry, and the Validator Station handoff. The result hierarchy and exact Buyer TRN finding are unchanged. This is a static local spike, not the production validator.
