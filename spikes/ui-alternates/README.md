# UI Alternates Spike

## Question

Which visual direction best improves the current EInvoiceCheck homepage and Validator handoff while preserving its identity and product grammar?

## Non-negotiable shared constraints

All variants retain only the current product's:

- color scheme: the current teal/navy/neutral semantic palette;
- flow: ERP output → EInvoiceCheck preflight → ASP, plus Prepare → Validate → Understand → Fix → Revalidate;
- validator entry and handoff semantics: upload/drop, paste XML, samples, in-memory messaging, and Validator Station handoff.

Everything else is available for experimentation: typography, shapes, textures, density, motion, component styling, layout, and local decorative assets.

## Variants

1. `001-playful-geometric` — shape-led grouping and tactile hard-shadow composition.
2. `002-handcraft-paper` — editorial workbench composition with paper, annotation, and handwritten treatments.
3. `003-vaporwave-outrun` — dense technical command-center composition with neon/CRT/grid treatments.

## Evaluation

Compare task clarity, trust, readability, accessibility, mobile behavior, and fit with EInvoiceCheck's existing calm preflight positioning.

These are disposable prototypes. Promote only a winning composition into a separately approved production design task.
